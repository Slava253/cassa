# 🏪 Магазин | Система кассы и бонусов

Полноценная система для управления магазином с поддержкой кассы, бонусных карт и весовых товаров.

## 📱 Возможности

### 👑 Администратор
- **Создание магазинов** - добавление новых магазинов с названием и адресом
- **Управление кассирами** - добавление/удаление кассиров с номерами карт
- **Управление клиентами** - просмотр и удаление клиентов
- **Просмотр статистики** - количество кассиров и товаров в магазинах

### 💳 Кассир
- **Поиск клиентов** - по номеру карты, телефону или никнейму
- **Скидки по карте** - автоматическое применение скидки при сканировании карты
- **Списание баллов** - 10 баллов = 1 ₽ скидки
- **Добавление товаров** - ввод штрихкода, названия, цены и цены со скидкой
- **Редактирование товаров** - изменение названия, цены и скидки
- **Удаление товаров** - удаление товаров из ассортимента
- **Весовые товары** - поддержка выпечки (в штуках), фруктов, овощей, морепродуктов (в кг)
- **Корзина** - добавление, удаление товаров, просмотр суммы
- **Оплата** - наличными (с расчетом сдачи) или картой
- **История покупок** - автоматическое удаление записей старше 7 дней

### 👤 Клиент
- **Единая карта** - штрихкод EAN-13 для всех магазинов
- **Профиль** - изменение никнейма и номера телефона
- **Выбор магазина** - просмотр ассортимента в любом магазине
- **Сканер цен** - сканирование штрихкода через камеру или вручную
- **Просмотр товаров** - список всех товаров в выбранном магазине с ценами
- **Бонусный баланс** - отображение количества баллов
- **История покупок** - просмотр последних покупок
