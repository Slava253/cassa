# 🅜 Marka — Система товаров, доставки и бонусов

Полноценная система для управления товарами, заказами, доставкой и бонусными картами. Подходит для интернет-магазинов, пунктов выдачи и служб доставки.

## 📱 Возможности

### 👑 Администратор
- Управление продавцами (добавление/удаление)
- Управление сотрудниками ПВЗ (добавление/удаление)
- Управление курьерами (добавление/удаление)
- Управление поддержкой (добавление/удаление)
- Просмотр клиентов и их балансов
- Создание и управление акциями

### 📦 Продавец
- Добавление товаров со штрихкодом
- Указание цены и размера (маленький/большой)
- Просмотр списка своих товаров
- Удаление товаров

### 💳 Сотрудник ПВЗ
- Поиск клиента по QR-коду
- Прием товара по штрихкоду
- Поиск заказов с отсканированным товаром
- Отметка заказа "Готов к выдаче"
- Выдача товара клиенту
- Возврат товара

### 👤 Клиент
- Просмотр каталога товаров
- Добавление товаров в корзину
- Оформление заказа
- Выбор способа оплаты (Сразу/При получении)
- Автоматическая генерация QR-кода для заказа
- Просмотр истории заказов
- Бонусный баланс

### 🚚 Курьер
- Просмотр заказов с доставкой
- Отметка заказа как доставленный

### 🆘 Поддержка
- Просмотр обращений клиентов
- Ответы на сообщения
- Закрытие обращений
