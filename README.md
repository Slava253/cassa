# 🏪 ГУ СВС | Система кассы и бонусов

Государственная система управления кассой и бонусными картами.

## 📱 Возможности

### 👑 Администратор
- Управление кассирами (добавление/удаление)
- Создание карт клиентов
- Просмотр всех клиентов и их балансов

### 💳 Кассир
- Сканирование карт клиентов (по номеру карты или телефону)
- Добавление товаров в корзину
- Проведение оплаты с начислением бонусов (5 баллов за 100₽)
- История операций

### 👤 Клиент
- Личный кабинет
- QR-код (электронная карта)
- Баланс бонусов
- История покупок
