# 🏪 Магазин | Система кассы и бонусов

## 📱 Возможности

### 👑 Администратор
- Управление кассирами (добавление/удаление)
- Создание карт клиентов
- Просмотр клиентов и балансов

### 💳 Кассир
- Сканирование карт клиентов
- Добавление товаров в корзину
- Проведение оплаты (5 баллов за 100₽)
- История операций

### 👤 Клиент
- Личный кабинет
- QR-код (электронная карта)
- Баланс бонусов
- История покупок
